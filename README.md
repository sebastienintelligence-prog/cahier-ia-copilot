- `index.html` — le cahier d'exercices (un seul fichier, fonctionne aussi hors ligne).

Toutes les données des exercices sont fictives. Le cahier ne fait aucun appel réseau et n'utilise aucun cookie : la progression et les saisies restent dans le navigateur de chaque participant.
